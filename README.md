# Discord Tool

Этот инструмент предоставляет возможность проверки токенов на валидность, очистку токенов, присоединение на сервера.
Из особенностей это его скорость, которая достигается с помощью многопоточности и поддержки прокси.

## Возможности

-   **Проверка токенов:** Проверяет валидность токенов и собирает информацию о них.
-   **Присоединение к серверу:** Присоединение к серверу по инвайт-коду.
-   **Очистка токенов:** Автоматически выходит из серверов, удаляет друзей и удаляет доступные лс токенов.
-   **Многопоточность:** Поддержка многопоточности для ускорения выполнения задач.
-   **Прокси:** Возможность использования прокси для обхода блокировок.
-   **Гибкая конфигурация:** Настройка параметров, таких как количество потоков, использование и тип прокси.
-   **Подробные логи:** Выводит процесс выполнения, ошибки и результаты.
-   **Сохранение результатов:** Сохраняет информацию в формате JSON для удобного анализа и последующей обработки.

## Установка

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/art3m4ik3/discord-tool.git
```

2. **Перейдите в папку проекта:**

```bash
cd discord-tool
```

3. **Установите зависимости:**

```bash
py -3 -m pip install -r requirements.txt
# или
python3 -m pip install -r requirements.txt
```

## Запуск

1. **Создайте файл `data/tokens.txt` и поместите в него токены, каждый на новой строке.**
2. **(Необязательно) Если хотите использовать прокси, создайте файл `data/proxies.txt` и поместите в него прокси, каждый на новой строке, в формате `ip:port` или `user:pass@ip:port`.**
3. **Запустите скрипт:**

```bash
py -3 main.py
# или
python3 -m pip install -r requirements.txt
```

4. **Следуйте инструкциям в меню для выбора нужного действия.**

## Использование

После запуска скрипта будет представлено меню с выбором. Выберите необходимый, введя номер пункта.

**Проверка токенов:**

-   Выберите режим проверки (стандартный или со сбором платежных данных).
-   Скрипт проверит валидность каждого токена и сохранит результаты в файлы `output/valid/tokens.json` и `output/invalid/tokens.json`.

**Присоединение к серверу:**

-   Введите код приглашения на сервер (Не ссылку. Например, ~~https://discord.gg/cats~~ cats).
-   Будет попытка присоединения к серверу и сохранит результаты в файлы `output/joined_servers.json` и `output/failed_servers.json`.

**Очистка токенов:**

-   Скрипт автоматически выйдет из всех серверов, удалит всех друзей и удалит доступные лс токенов.
-   Результаты будут сохранены в файлы `output/valid/tokens.json` и `output/invalid/tokens.json`.

**Настройки:**

-   Измените параметры, такие как использование прокси, тип прокси и количество потоков.
